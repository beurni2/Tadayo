C. Four points kept for this stage's brief (handoff 7's brief, section 4)

12. G01-invite-people-accept-again: Ben's invitation list for Sunday people, where Sam accepted an earlier version of the roster and must accept this one (a link state the API calls "used"). Sam's row: its status words, with Share again. The server refuses Create new link and Revoke link for a link already used to accept, so the row offers neither. Also say how a row reads "Proposed by" in a roster the server made because someone accepted under another name (FQ84): it keeps the member whose link was used as its proposer. Handoff 4's G01-invite-people-revoked is the closest frame.
13. G01-pending-approve: the first roster's waiting screen when Ben, the creator, must approve a roster revision the server made because the person who accepted is named differently from the name Ben typed (FQ84). Handoff 4's G01-pending says "The club starts when another person accepts the same roster.", which isn't true here: show that Ben's own approval is needed, and the way to it (Review members). Home before the club starts (H01-awaiting-activation) says the same sentence: say whether the same new words apply there.
14. G05-members-invite: where Ben shares and manages a later addition's link once Sunday people has started. FQ51's default reaches the invitation list only during setup. Handoff 3's detailsRoute puts the optional invitation control in Club details, and handoff 5's invitationControl places Invite someone "below Members and above Schedule … only when the server authorizes a proposal and capacity permits", as handoff 6's G05-club-details-paused draws it for a paused club. Draw it for an active club, and where the new person's link is then shared and managed, or say where it belongs instead.
15. G02-changed-name: G02-changed when what changed is the viewer's own place: Debby opened the link Ben made for Leila in Kitchen table and accepted, and since Debby's profile name isn't Leila, the server made a new roster with "Debby · You" where Leila was (FQ66; the API contract's own example). Handoff 2's G02-changed says "The people in Kitchen table have changed.", which reads as if someone else changed.
